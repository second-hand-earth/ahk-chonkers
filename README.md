# AutoHotkey Scripts for Chonkers

A couple of scripts to automate litterbox cleaning, bowl refilling, and clicking on distractions.

## Features

### `auto_litterbox`

- [Demo](https://youtu.be/lXStp_FI8V8?si=FLxkxErN_kfOub6G)
- Cycles through your rooms, cleaning the litterboxes and refilling the food bowl before moving on to the next room.
- Optional: after cycling through the rooms, repeatedly clicks in one spot to collect distractions while waiting for a litterbox to fill again.
- Press **F6** to start or pause the script. Press **Esc** to quit.
- Before running the script, set `total_rooms` to the number of rooms that have litterboxes.

### `auto_distraction_clicker`

- [Demo](https://youtu.be/rPU0ZKaOWQ8)
- Automatically clicks on distractions.
- Set the game to **Chill mode** before running.
- Does not click on the golden distraction.
- Press **F8** to start or pause the script. Press **Esc** to quit.
- Tested only in the Zen room setting.

## Requirements

- Windows
- [AutoHotkey](https://www.autohotkey.com/) v2.0

## Installation

1. Install AutoHotkey v2.0.
2. Clone or download this repository.
3. Double-click the script you want to run.
